# 保存並暫停

老闆明確要求 save 時，整理工作目標、原始對話或來源、已授權範圍、目前進度、驗收證據、尚未完成事項與可執行下一步，保存到工作區 `.shiftblame/tmp/` 的 Markdown 草稿。保護敏感資料，記錄來源而非金鑰。以可辨識且屬於本工作、避免覆蓋其他工作的 ASCII 名稱，以及不含空白的相對草稿路徑，執行單獨命令 `sb handoff save <名稱> <草稿路徑>`。先核對保存成功；失敗則保留草稿與現況，回報原因。

非 Git 工作區以工作目錄內的文件保存同樣的脈絡與下一步，核對檔案後結束回合；載入時依該文件及原對話接續。

成功後告知保存位置及未完成事項，結束本回合，等待老闆明確載入或續作。保存代表暫停，完成與驗收狀態維持原樣。自動 Git 整理及一般交接不視為暫停指示。

載入時依 [load](../load/SKILL.md) 核對並接續。切換工作時先保存目前工作，再依老闆指示載入另一工作。
