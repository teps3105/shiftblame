# 恢復工作

依 [主技能](../shiftblame/SKILL.md) 與 `sb state` 核對 repo、分支及工作樹。使用者已指定工作就接續，進度詢問與補充資訊沿用原目標及有效授權。

## 定位與讀取

依 [HANDOFF](../shiftblame/references/HANDOFF.md) 執行 `sb handoff load`，自動按 `savedAt` 選取目前 repo 最新快照；已知 task 時使用 `sb handoff load <task>`。命令完整輸出交接並完成檢查後，清空本次載入開始時目前 repo 的全部交接快照，包含其他 task。草稿、產品檔案及其他 repo 保留。

需要保留快照供查閱時，使用唯讀的 `list` 與 `show <task>`。沒有具名快照時，依使用者回指與工作筆記找原稿，不依檔案修改時間猜測最新授權。

## 核對與接續

核對原對話、正式文件與實際 Git 狀態。交接只提供定位，不能產生新授權或代替來源。直接接續，恢復本身不是提問理由；停止條件依主技能。

保留既有變更，判斷哪些工作已完成、哪些證據已失效。分支或 repo 不符時先定位正確工作區，不擅自切分支、還原檔案或重做已完成內容。

載入成功代表交接已完整輸出及快照消耗，不代表產品驗收完成。缺檔、損壞、鎖衝突、Git 查證或輸出失敗時保留資料，先處理診斷，不猜用較舊快照。後續需要交接時依 [save](../save/SKILL.md) 保存新落點。

從已核對的下一步開始，觀察預期結果並持續完成已授權任務。
