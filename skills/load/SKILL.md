# 載入並接續

非 Git 工作區先讀取保存的工作文件與原對話，核對目前資料後直接接續。

Git 工作區依使用者指定的名稱或原對話定位工作；名稱不明時用 `sb handoff list` 與 `sb handoff show <名稱>` 核對。執行 `sb handoff load <名稱>`，讀取保存的工作目標、進度、來源與下一步，並重新整理當前 Git 資訊。核對原對話、授權、工作區及已完成證據，再直接從可執行的下一步接續，直到完成已授權範圍或遇到停止條件。保存資訊只供定位與核對，授權仍依老闆原指示。

保護既有變更；不一致、缺失、損壞或有鎖衝突時先診斷，保留來源。已停止的 3D 製作依老闆指示恢復。無具名交接時依原對話與正式來源核對；`sb handoff load` 可讀取目前 Git，無法單憑它推定原工作。
