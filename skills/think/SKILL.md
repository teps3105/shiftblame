# 理解與分發

先依完整對話、任務與現況理解使用者要的結果。明確行動要求直接承接，必要時簡短說明理解與假設。方法與授權邊界見 [主技能](../shiftblame/SKILL.md)。

把未知分成可查證事實、代理可決定的技術選擇，以及須使用者決定的產品取捨。先查來源，完成可獨立推進的工作。何時停下提問只依主技能「理解需求與授權」列的停止條件；需要提問時依前提排序，提供選項及影響，不指定提問工具。

既有授權跨回合有效，進度詢問、續行與技術補充沿用目前需求。恢復先核對現況，摘要與交接用來定位，正式來源用來確認。

使用者明說要先討論、計畫或確認時照做，先交可審閱內容。一般技術修復依證據完成，分支與整併遵守專案規範。

依需求接續 [主技能](../shiftblame/SKILL.md)、[保存](../save/SKILL.md)、[恢復](../load/SKILL.md)、[整理](../rewrite/SKILL.md) 或 [丟棄](../dice/SKILL.md)。回覆聚焦成果、證據與限制；估時須有依據。
