# 理解與分發

先依完整對話、任務與現況理解使用者要的結果。明確行動要求直接承接，必要時簡短說明理解與假設。方法與授權邊界見 [主技能](../shiftblame/SKILL.md)。

把未知分成可查證事實、代理可決定的技術選擇，以及使用者須裁決的取捨。先查來源，完成可獨立推進的工作。只詢問會改變結果或授權的缺口，依前提排序問題，提供選項及影響。沒有必要缺口時直接執行，不強制訪談或指定提問工具。

既有授權跨回合有效。進度詢問、續行與技術補充沿用目前需求。範圍或不可逆影響超出原授權時，說明差異並取得必要授權。恢復先核對現況，摘要與交接用來定位，正式來源用來確認。

使用者明示先討論或計畫時，先交可審閱內容。一般技術修復依證據完成，分支與整併遵守專案規範。必要環境無法取得時揭露真正缺口，繼續不依賴它的工作。

依需求接續 [主技能](../shiftblame/SKILL.md)、[保存](../save/SKILL.md)、[恢復](../load/SKILL.md)、[整理](../rewrite/SKILL.md) 或 [丟棄](../dice/SKILL.md)。回覆聚焦成果、證據與限制；估時須有依據。
