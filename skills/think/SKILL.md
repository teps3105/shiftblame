# 理解與分發

先依對話、任務與現況理解使用者要的結果。必要時用一句白話說明你的理解，差異、假設或缺少的關鍵資訊才展開。技能以當前平台提供的讀取方式使用。

明確行動要求直接承接；既有授權跨回合有效。進度詢問、續行及技術補充沿用目前需求。實質修改目標、範圍、成本／風險容忍或破壞性操作時，揭露差異並取得必要授權。等待回覆期間持續完成既有授權內的工作；時點審查與判定期間可依[主技能](../shiftblame/SKILL.md)先行研究。新增權限須有明確授權。

使用者明示要先討論、計畫或確認時，先交可審閱內容。依完整語境理解意圖與續行要求；點名技能時，按其目的承接適用工作。

需要澄清時先分出可查證的事實、代理可決定的技術選擇，以及必須由使用者決定的取捨。事實先查、技術選擇依證據處理；只把影響結果或授權的缺口交給使用者。依問題的前提排序，少量互不相依的問題可一起提出，附建議及影響；答案依賴尚未確定前提的問題留待前提成立。沒有阻止當前已授權工作的必要缺口，就接續工作。

沿用活動 slug 或明確指定的路由；一般小型工作在既有授權範圍直接實作。必須建立新 slug／分支而路由未定時才問。先完成已授權、可讓選項具體化的唯讀與準備工作；一般技術問題由代理依證據判斷。

執行中依證據修正做法；符合已核准需求的技術修復自主完成。無法取得必要環境或資訊時說明真正缺口，其餘獨立工作繼續。

回覆以使用者需要的結果為主，指出變更、證據與實際限制；篇幅及格式依內容選擇。估時僅在有合理依據時提供。當技能真的造成停等或偏離任務，明確指出該文件與相關規則。

狀態損壞先查證及修復，保持提交與正式流程推進封閉；修復後用 sb state 核對。記錄須有真實來源，操作須在既有授權內。

分發至 [主技能](../shiftblame/SKILL.md)、[保存](../save/SKILL.md)、[恢復](../resume/SKILL.md)、[整理](../rewrite/SKILL.md) 或 [丟棄](../dice/SKILL.md)。只有尚有必須由使用者決定的事（可先行的研究告一段落後）、實際阻塞、明示暫停／取消或整體完成時結束回合。
