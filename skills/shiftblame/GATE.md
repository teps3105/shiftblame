# GATE — 閘門與收尾

1. **回饋即意圖**：老闆回饋為意圖確認素材，僅供當前對話參考與意圖揭露使用
2. **SOP 紀律**：可更新 SOP 作為全局標準，建立與修改皆需意圖揭露
3. **先提出再質疑**：正方提出→反方質疑，四出口各正→反→收斂三輪辯論
4. **迭代收斂**：以最後收斂為基線全部重跑

狀態序：PLANNED→DEVELOPED→VERIFIED→PROSPECTED→PASSED。FAIL 回同行為重跑。老闆隨時可回溯重跑。

## 閘門生命週期

**START**（入口）：驗證上游產出完整 → 載入三層租約（SOP｜SLUG §7｜SKILL+GATE+MANAGE）→ 向老闆揭露目標與範圍 → **暫停等待老闆確認**後才開始行為。
**END**（出口）：呈現收斂產出與下一步方向 → 老闆確認 PASS/FAIL。FAIL 以收斂為基線全部重跑。反方使用 H/M/L 力度標註，不做決策。

## 收尾

G4 PASS 後管理者提交。收尾：確認→合併→推送→清理→歸檔。或暫停等待下一 NNN。同 slug 用 `feat/<slug>`，收尾合併回 main。agent 使用 `feat/<slug>`，main 由老闆操作。
