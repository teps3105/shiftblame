# godot-mcp — Godot 實作工具

## 適用

Godot 專案、場景、節點建立與操作，sprite 載入，mesh library 匯出。

## 能力

`list_projects`、`get_project_info`、`get_uid`、`update_project_uids`、`launch_editor`、`create_scene`、`add_node`、`save_scene`、`load_sprite`、`export_mesh_library`。

## 使用

G2/EXECUTOR 需要操作 Godot 結構時使用；runtime 驗證改讀 `TOOLS/E2E/godot-mcp.md`。
