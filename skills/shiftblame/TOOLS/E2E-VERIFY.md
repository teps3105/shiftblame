# 端到端驗證工具包

本文件整理 shiftblame 可用的端到端驗證工具，供 DEV 在 L2 執行實機驗證時依專案類型選用。後續新增工具時直接追加列表項目即可。

## 工具列表

### Chrome DevTools MCP

- **適用場景**：網頁應用端到端驗證
- **定位**：透過 MCP 協定操控 Chrome 瀏覽器，執行真實使用者操作並驗證結果
- **能力**：
  - 截圖與 DOM 快照（視覺驗證）
  - 點擊、填寫、拖曳、鍵盤操作（互動模擬）
  - 網路請求監控（API 驗證）
  - Console 訊息檢查（錯誤偵測）
  - Lighthouse 效能分析（效能驗證）
  - Heap 快照（記憶體驗證）
- **在 shiftblame 中的使用方式**：
  - DEV L2：執行網頁端到端實機驗證（開啟頁面 → 操作 → 截圖驗證 → 確認行為符合 PM 規格）
  - 驗證結果寫入 result.md「驗證」段
