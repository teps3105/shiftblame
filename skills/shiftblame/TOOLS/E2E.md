# 端到端驗證工具

本文件整理 shiftblame 可用的端到端驗證工具，供各角色在宣告通過後應使用的執行工具。後續新增工具時直接追加列表項目即可。

## 工具列表

### Chrome DevTools MCP

- **適用場景**：網頁應用端到端驗證
- **定位**：透過 MCP 協定操控 Chrome 瀏覽器，執行真實使用者操作並驗證結果
- **能力**：
  - 截圖與 DOM 快照（視覺驗證）
  - 點擊、填寫、拖曳、鍵盤操作（互動模擬）
  - 網路請求監控（API 驗證）
  - Console 訊息檢查（錯誤偵測）
  - Lighthouse 效能分析（效能驗證）
  - Heap 快照（記憶體驗證）
- **在 shiftblame 中的使用方式**：
  - G2 正方：執行網頁端到端實機驗證（開啟頁面 → 操作 → 截圖驗證 → 確認行為符合 G1.md 規格）
  - 驗證結果寫入 G2.md 收斂段
- **降級替代**：Chrome DevTools MCP 不可用時，降級為 CLI smoke test（建置/啟動/請求回應驗證）＋老闆肉眼開瀏覽器覆核；無法以純 CLI 覆蓋的視覺/互動行為須明確回報未驗，不得假裝看過（§17.0 platform-agnostic）
