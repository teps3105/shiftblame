# 獨立性工作工具（codex）

本文件整理 shiftblame 中承擔「需要外部獨立性／利益衝突隔離」工作的外部工具。codex 從「特殊外部角色」降回普通外部工具之一（見 SKILL §17.2），與其他外部工具平起平坐，此處載明其能力邊界。後續新增工具時直接追加列表項目即可。

## 工具列表

### codex（codex-rescue plugin）

- **適用場景**：反方獨立複審、成果驗收、code review、外部資訊查證（本地工具不足時）、圖像識別（ai-vision 不足時）
- **定位**：獨立性升級鏈的外部擔任者（見 SKILL §17.0 獨立性升級鏈）；走不同網路出口／限流配額，本地 429 不代表 codex 也 429。framework 內 agent 對 codex 的所有外部需求**一律走 `/codex:rescue`**，禁側通道
- **能力**：
  - 基底工具：Bash（codex-rescue agent 唯一 tool）
  - 承擔工作：反方獨立複審（雙層反方的外層）、成果驗收、code review、查證任務、圖像識別粗篩
  - 純文字任務：反方複審／查證／驗收，任務 prompt 須明確「不得觸發 computer use、不得操作瀏覽器與桌面、只讀本機檔＋文字產出」
- **在 shiftblame 中的使用方式**：
  - 雙層反方：反方子代理先做初步反方（正方為主 session 非子代理），codex 再疊加獨立複審（外部利益衝突隔離），見 SKILL §17.2
  - 成果驗收：slug 末強制驗收預設擔任者，見 SKILL §17.3
  - 外部查證：本地 web 硬約束時升級必須調用，見 SKILL §17.0／§17.3
  - diff 取得：`task` 子命令不支援 diff 自動抓取，prompt 須附 diff 內容或指示 codex 自跑 `git diff`
- **降級替代**：codex 不可用時，反方複審／成果驗收降級獨立子代理（read-only）＋老闆親驗；外部查證降級內建 web（若可用）或押後到 codex 查證可行時機（見 SKILL §17.0 推進禁令、§17.3 驗收擔任者三層）
