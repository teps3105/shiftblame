# 文件品質

依讀者要完成的工作組織文件。repo 根 README 提供入口；模組 README、API 指南、操作說明與設計理由可依專案慣例存在。每個事實有明確權威位置，其他文件引用，避免矛盾的複製。

說明實際行為、適用條件、必要命令及可核對來源。設計理由有決策或證據支持時保留；主觀假設標明假設。程式碼、路徑、簽章與行號在有助理解或操作時引用必要片段。

同批更新受本次行為變更影響的文件。機密、本機私有配置及內部拓撲保留在適當的受保護位置。工作過程與診斷放 .shiftblame/tmp/，正式文件寫當下有效內容。

驗證讀者能否依文件完成目標、引用是否有效、描述與實況是否一致。
