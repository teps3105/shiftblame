# PM ATTACK — L3 紅隊

> 階段：L3 ｜ 執行者：依複雜度（對話內 / 子代理）｜ 上下文：見 MANAGE.md

## 子代理上下文需求

若判定為高複雜度需開子代理，派工 prompt 必須提供：

1. **角色**：紅隊
2. **攻擊標的**：result.md 全文
3. **任務宣告**：task.md 宣告內容
4. **讀寫規則**：同 EXECUTE.md

## 攻擊方向

- 研究可信度、需求完整性、設計品質、範圍控制
- PM 特定攻擊點：
  - 需求是否完整且可驗收
  - GWT 測試案例是否可執行
  - 前端設計規格是否明確
  - 範圍是否與宣告一致

## 審查規範

- 不得立即修復，必須繼續藍隊
- 流程合規聲明
