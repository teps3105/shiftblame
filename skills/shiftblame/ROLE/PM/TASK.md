> L1 ｜ 依複雜度 ｜ 研究期 ｜ PM 無上游
> 依計畫執行所有產出，成果寫入 task.md。前端設計限文字規格，不產出可執行程式碼。完成後 commit。

## 面向差異

| | 研究面向 | 品管面向 |
|---|---|---|
| 觸發時機 | 需求釐清、功能研究 | 品質偏移、標準不明 |
| L1 重點 | 需求分析、PICA、前端設計 | 偏移分析、校正、一致性檢查 |
| 產出特徵 | 功能規格、PICA、設計規格 | 校正報告、修訂方案 |
| 驗收標準 | 規格完整、驗收標準可執行 | 偏移已修正、標準已校正 |
| 攻擊焦點 | 需求漏洞、規格缺口 | 品質標準缺口、校正不完整 |
| 防禦焦點 | 規格完整性、DEV 可執行性 | 品質有效性、一致性恢復 |

## 執行規範

- 依計畫執行；前端設計限文字規格，不產出可執行程式碼；成果寫入 task.md
- PM 僅產出需求，禁止提出實作計畫（改哪些檔案、怎麼改屬 DEV L0 職責）
- commit：`git commit -m "feat(<slug>): <繁中標題>"`
- PM 不碰程式碼；需程式碼理解時標記為 DEV 待辦
