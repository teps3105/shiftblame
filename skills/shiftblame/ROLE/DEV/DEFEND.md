# DEV DEFEND — L4 藍隊

> 階段：L4 ｜ 執行者：依複雜度（對話內 / 子代理）｜ 上下文：見 MANAGE.md

## 子代理上下文需求

若判定為高複雜度需開子代理，派工 prompt 必須提供：

1. **角色**：藍隊
2. **紅隊報告**：red.md 全文
3. **原始產出**：result.md 全文
4. **任務宣告**：task.md 宣告內容
5. **上游規格**：PM conclusion.md（對照實作）
6. **讀寫規則**：同 EXECUTE.md

## 防禦方向

- 功能完整性對照上游定義
- 確認上游全部功能與 result.md 一致
- 紅藍對照 + 中文摘要
- DEV 特定防禦點：
  - PM 規格是否完整實作
  - GWT 是否全部通過
  - 程式碼是否鎖定（EXECUTED 後不動）

## 流程合規

- FAIL → 退回 DECLARED 重新宣告
- PASS → 管理者產出 conclusion.md

- **回應**：（回應理由）
- **行動**：原地修正 / 不修正

## 結論

PASS / FAIL
