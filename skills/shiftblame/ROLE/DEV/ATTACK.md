# DEV ATTACK — L3 紅隊

> 階段：L3 ｜ 執行者：子代理（強制）｜ 上下文：隔離

## 子代理上下文需求

派工 prompt 必須提供：

1. **角色**：紅隊
2. **攻擊標的**：result.md 全文
3. **任務宣告**：task.md 宣告內容
4. **上游規格**：PM conclusion.md（對照實作）
5. **讀寫規則**：同 EXECUTE.md

## 攻擊方向

- 功能完整性、GWT 通過、技術品質、安全效能
- DEV 特定攻擊點：
  - 上游功能是否做出（對照 PM conclusion.md）
  - GWT 是否全部通過
  - 技術選型是否合理
  - 前端是否遵循 PM 規格
  - 程式碼品質、安全性、效能

## 審查規範

- 不得立即修復，必須繼續藍隊
- 流程合規聲明

## red.md 產出格式

```markdown
# 紅隊攻擊報告 — <slug> DEV/<NNN>

## 攻擊摘要

（紅隊填入整體評估）

## 攻擊點

### A1: （攻擊點標題）
- **嚴重性**：HIGH / MEDIUM / LOW
- **類型**：遺漏 / 不一致 / 邏輯錯誤
- **描述**：（具體問題）
- **證據**：（檔案與行號）

## 結論

PASS / FAIL
```
