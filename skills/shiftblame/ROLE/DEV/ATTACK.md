# DEV ATTACK — L3 外部攻擊

> 階段：L3 ｜ 執行者：依複雜度（對話內 / 子代理）｜ 立場：外部對手

## 定義

L3 為**外部攻擊**階段。攻擊者以外部對手立場，對整體產出進行一切滲透、攻擊、破壞行為。不限於攻擊 result.md，而是對產出的完整攻擊面進行測試。

## 子代理上下文需求

若判定為高複雜度需開子代理，派工 prompt 必須提供：

1. **角色**：外部攻擊者
2. **攻擊標的**：result.md 全文 + 所有相關產出
3. **任務宣告**：task.md 宣告內容
4. **上游規格**：PM conclusion.md（對照實作）
5. **讀寫規則**：同 EXECUTE.md

## 攻擊方向

外部攻擊者的完整攻擊範圍：

- **滲透**：功能漏洞、邊界遺漏、未處理的邊角案例、安全盲點
- **攻擊**：邏輯缺陷、技術品質、效能瓶頸、架構弱點
- **破壞**：上游功能未實作、GWT 未通過、前端未遵循 PM 規格、程式碼品質破壞

DEV 特定攻擊面：
- 上游 PM 規格是否完整實作（對照 conclusion.md）
- GWT 是否全部通過
- 技術選型是否合理
- 安全性、效能、程式碼品質
- 前端是否遵循 PM 規格

## 審查規範

- 不得立即修復，必須繼續 L4
- 流程合規聲明

## red.md 產出格式

```markdown
# 外部攻擊報告 — <slug> DEV/<NNN>

## 攻擊摘要

（攻擊者填入整體評估）

## 攻擊點

### A1: （攻擊點標題）
- **嚴重性**：HIGH / MEDIUM / LOW
- **類型**：滲透 / 攻擊 / 破壞
- **描述**：（具體問題）
- **證據**：（檔案與行號）

## 結論

PASS / FAIL
```
