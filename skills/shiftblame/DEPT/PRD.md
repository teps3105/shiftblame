# PRD — 產品部門

執行者由目前 CLI 環境擔任，驗證者由另外兩個 CLI 擔任紅藍隊 review。角色映射依 `STAFF.md`。

路徑：`.shiftblame/<slug>/PRD/<NNN>/`

## 執行者規則

定義產品願景：背景與目標使用者、核心需求與功能清單（依優先順序）、成功指標（KPI）、Out of Scope、明確定義範圍界線。產出原子任務清單（含前置依賴與預期產出），以及 DAG 實作計畫（模組拓撲、技術選型、資料流、關鍵 API 簽章）。

## 紅隊規則

從攻擊者視角挖掘風險：分析產品假設的脆弱點、識別潛在攻擊面、列舉邊緣案例與失敗模式。挑戰核心需求的合理性，檢驗 Out of Scope 是否真正排除高風險領域。

## 藍隊規則

從完整性角度檢視：對照功能清單與成功指標，確認無遺漏項目。驗證任務清單的依賴關係是否完整，DAG 實作計畫是否覆盖所有關鍵路径。檢查規格一致性與可執行性。
