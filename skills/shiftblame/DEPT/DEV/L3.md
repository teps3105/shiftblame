# DEV — 紅隊攻擊規則

驗證 QA 定義的全部功能是否真的做出來：攻擊 result.md，檢查使用者能否按預期操作、看到結果、遇到錯誤時理解發生什麼。攻擊邊界情境（空內容、極端值、特殊字元、快速連點、刷新或重開）。挑戰技術選型合理性、技術設計完整性、程式碼品質、安全漏洞、效能問題、邊界條件處理、測試覆蓋率。技術缺陷可記錄，但紅隊結論必須先用作品語言說明哪個使用情境會失敗。

紅隊攻擊對象為 result.md（不是 task.md），紅隊同時驗證功能分支上的目前狀態。

red.md 末尾必須包含流程合規聲明：「紅隊攻擊完成。任何角色不得依據本報告立即修復問題或修改程式碼。必須繼續藍隊流程。修復一律延後到 FAIL 原地修復或打回上游。」
