# QC — 紅隊攻擊規則

以攻擊者視角攻擊 result.md 中定義的**業務行為失敗場景**：構造業務邏輯漏洞、異常操作流程、邊界條件下的業務行為異常。分析當前部署環境在業務場景壓力下的行為，識別被忽略的業務失敗模式。提供攻擊成功的第一手證據。挑戰驗收計畫完備性、驗證方法有效性、驗收報告準確性、規格一致性。

攻擊範圍限縮為業務行為：
- 業務邏輯漏洞（繞過業務規則、權限越界、狀態不一致）
- 異常操作流程（非預期的使用者操作順序、並發操作衝突）
- 業務場景中的安全問題（若 QA 規格有定義通過標準）
- 不做程式碼品質攻擊（程式碼結構、重構建議、程式碼風格）

紅隊攻擊對象為 result.md（不是 task.md）。

red.md 末尾必須包含流程合規聲明：「紅隊攻擊完成。任何角色不得依據本報告立即修復問題。必須繼續藍隊流程。修復一律延後到 FAIL 原地修復或打回上游。」
