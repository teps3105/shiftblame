# QC — 執行者產出規則

依已確認的宣告，將驗收計畫、驗收報告、驗收結論產出為 result.md，包含三段：驗收計畫、驗收報告、驗收結論。每段聚焦業務驗證結果——當前部署環境的業務行為是否正確實現。不得建立「驗收計畫.md」、「驗收報告.md」或「驗收結論.md」；內容必須彙整業務驗證計畫、實測證據、完成紀錄與 PASS/FAIL 判定。

**雙循環產出規則**：
- 計畫循環：result.md 只含驗收計畫（不做實際驗證）
- 實作循環：在既有 result.md 後追加驗收報告+驗收結論（以 `---` 分隔），開始實際驗證

禁止在 result.md 中立即修復紅隊指出的問題。result.md 記錄本輪工作成果；修復一律延後到 FAIL 原地修復或打回上游。
