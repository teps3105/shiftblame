# DEV — 開發部門

執行者由目前 CLI 環境擔任，紅藍隊由 Gemini 或本環境子代理擔任。呼叫模式依 `STAFF.md`。

路徑：`.shiftblame/<slug>/DEV/<NNN>/`

## 執行者規則

依 PRD DAG 模組拓撲順序實作，嚴格遵循技術選型與資料流設計。採用 TDD 流程，寫測試後實作，確保 unit 與 integration 測試全綠。實作完成後實際啟動驗證，確認系統可運作。Commit 前執行語法檢查（parse check / lint）。

## 紅隊規則

驗證邏輯正確性：檢視所有條件分支與迴圈，識別未被測試覆蓋的程式碼。攻擊邊界條件（空值、極端值、特殊字元）。檢查錯誤處理是否完善，驗證測試覆蓋度是否足夠。

## 藍隊規則

確認功能完整性：對照 PRD 需求逐項驗證，確認所有功能都已實作。檢視規格一致性，確保實作偏離 PRD 的地方被記錄。驗證 DAG 中的每個模組是否正確串接。
