# SBM-TM-G3 — 共識後執行規劃層

## 1. 範圍

G3 承接 G1+G2 收斂基線，產 `<plan>` 供執行者執行。G3 為**非正反收斂軌**（正反收斂限 G1+G2，見 SBM-SKILL §5.13）。G3 反方合理性未經業界先例充分證成（見 .shiftblame/ROADMAP.md TD5）；殘留風險由 SBM-GATE §7.1 觸發點② 獨立審核承擔。規範詞彙依 SBM-SKILL §3.1。讀寫中文 MUST 使用 UTF-8。

## 2. `<plan>` 產出格式

`<plan>` = 實作策略 + 行動序列 + 驗收流程；第四段「變更預案」為條件段（無預期風險時可省略）。`<plan>` 為容器：內含 `<task>` 參照 + 明確化 `<complete>` + 實作策略 + 驗收流程。

| 段 | 內容 | 權威來源 |
|----|------|----------|
| ① 實作策略 | 複雜度判定 → 派發策略 | SBM-GATE §6 |
| ② 行動序列 | `<task>` 執行順序+依賴 | G1 `<task>` |
| ③ 驗收流程 | 明確化 `<complete>` 當輪清單 | SBM-TM-G2 §5.3 格式 |
| ④ 變更預案（條件） | Minor/Major 預期風險 | SBM-GATE §6 |

本檔只寫當輪最新 `<plan>`，禁止跨輪累積敘事；歸檔以 git 歷史為權威。

## 3. 邊界

- 計畫方向／技術選型：歸 G1/G2 正反收斂
- G3 不參與正反收斂
- PASS/FAIL 歸 slug 層級由老闆
