# 開新對話閘門

每個 slug 完成收尾歸檔後，管理者輸出完成摘要並建議老闆開啟新對話，停止處理下一個 slug 的工作。下一個 slug 在全新對話中啟動。

## 新對話恢復流程

讀取 ROADMAP.md 確認進度 → 讀取 REPO.md 確認架構現狀 → 讀取前一個歸檔 slug 的 SLUG.md 確認殘餘風險與交接事項 → PRD 再掃描（檢查是否有新增/更新 PRD）。

## 適用模式

OPERATE（含 AUTO 子模式）和 MANUAL 模式每個 slug 完成後都應開新對話。PLAN 模式下管理者評估上下文用量，若未達閾值可選擇不開新對話。

## 壓縮提示

AUTO 模式下，管理者在壓縮前輸出提示訊息，說明目前 slug 狀態與壓縮後恢復方向。
