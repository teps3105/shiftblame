# 整理有效文件

按 [主技能](../shiftblame/SKILL.md) 的授權及契約邊界工作。依當前平台讀取本技能後執行。

先定位此次變更影響哪些定義、引用與證據。修正或刪除已失效內容，保留仍成立的部分；局部變更更新對應段落。跨多處相互矛盾或全面改變治理時，完整重讀並收斂。

G1 已封存的契約改義須重新核准。G2／G3 的技術修正只更新受影響內容；執行證據依穩定 AC／技術項更新，避免同一事項留下矛盾版本。需要保留對照且來源不在 git 時，先保留必要原稿至 tmp，並保護使用者材料。

SLUG 更新原有狀態與索引，保留需求來源、未完工作與有效技術債。SOP／ROADMAP 同步實際改變的規則及方向；只有全面治理調整才逐條全審。sb sopreview 可記錄範圍與結論；重審由規則及方向的實際變更觸發。

回讀改動及直接依賴，確認引用、契約與實況一致。成果應能離開當前對話理解；方法本體描述當下適用條件、做法與驗收；歷史由 git 或適用的工作記錄承載。

重整方法入口、術語與決策理由時依 [DOCS](../shiftblame/assets/DOCS.md) 保留唯一權威及明確觸發。先修正重複、過時、失去用途的內容，必要參考保留可發現的入口；以實際任務檢查改寫是否改善使用，單純字數減少不代表品質提高。
