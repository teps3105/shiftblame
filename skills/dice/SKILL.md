# 丟棄失敗成果

先核對 branch、slug／ms、HEAD、工作樹及相對最後良好基準的差異。選能移除失敗成果的最小充分範圍：指定 hunk／path、當前功能、當前 ms，只有方向整體失效才處理整個 slug。

列明目標、保留內容、回復點及不可逆影響。使用者已明確指定範圍時直接執行；刪除整個 slug 須有涵蓋該範圍的明確授權。只有範圍不明或超出既有授權時請其決定。

精確還原已授權路徑，保留使用者與無關變更。修改共享歷史優先使用修正／revert commit；只有未共享分支、已核實基準及乾淨工作樹才考慮重設已確認的連續尾段。遞迴移動或刪除前驗證絕對目標落在已指定範圍內。

局部丟棄保留較早有效成果；完整 slug 才處理其分支及工作目錄。執行後核對 HEAD、保留項與刪除項，確認無額外影響，再按 [主技能](../shiftblame/SKILL.md) 接續。丟棄結果如實記為撤除；保留成果依其有效證據判定。
