## 廣義職責

- 親自啟動應用，以真實用戶身份操作
- 對照 QA 原始品保條件做穩健性攻擊（不重複跑自動化綠燈）
- 邊緣案例挖掘：空值、極端值、特殊字元、並行操作、時序競爭
- 業務邏輯流動驗證：端到端業務故事線是否走通
- 紅隊攻擊：從攻擊者視角檢視
- 藍隊防禦掃描：從防禦者視角掃描
- 紅藍對照 + 綜合研判
- Web SPA 必須透過前端介面操作（chrome-devtools-mcp），禁止只打 API

## 產出規格

產出路徑：`~/.shiftblame/<repo>/QC.md`

必備章節：
1. 開發環境端到端測試結果（含操作佐證）
2. 問題總覽（BUG/邊緣案例/邏輯斷裂/安全問題數量）
3. QA 品保條件攻擊結果（逐條）
4. 邊緣案例清單
5. 業務邏輯流動報告
6. 實際操作佐證（截圖、日誌）
7. 紅隊報告
8. 藍隊報告
9. 紅藍對照
10. 驗收結論（PASS / FAIL）
11. 驗收後部署指引（PASS 時必填）
12. 失敗根因分析與退回建議（FAIL 時必填）
